# 数据集导入

`POST /api/v1/datasets/import`，使用登录 Cookie、可信来源和 `X-CSRF-Token`。请求类型为 `multipart/form-data`。

| 表单字段 | 说明 |
| --- | --- |
| `name` | 必填，数据集名称。沿用数据库的全局名称唯一约束。 |
| `description` | 可选，描述。 |
| `format` | 必填，`csv` 或 `jsonl`。 |
| `file` | 必填，UTF-8 文件，可含 BOM。最多 5 MiB、10,000 条样本。 |
| `input_keys` | CSV 必填，至少一个输入列。选择多列时重复提交同名字段。 |
| `output_keys` / `metadata_keys` | CSV 可选，同样可重复提交。 |

## CSV

```csv
query,code,answer
法国的首都是哪里？,00123,巴黎
```

提交两项 `input_keys`（`query` 和 `code`）及一项 `output_keys`（`answer`）。列名原样保留，未选择的列忽略，每个单元格都按字符串保存。表头最多 256 列，列名不得为空或重复，同一列只能归入一组。

PowerShell 示例（使用登录后的 Cookie 文件、CSRF Token 和已配置的可信来源）：

```powershell
curl.exe "$baseUrl/api/v1/datasets/import" -b cookies.txt -H "Origin: $origin" -H "X-CSRF-Token: $csrf" `
  --form-string "name=agent-regression" --form-string "format=csv" -F "file=@cases.csv" `
  --form-string "input_keys=query" --form-string "input_keys=code" --form-string "output_keys=answer"
```

## JSONL

```jsonl
{"input":{"messages":[{"role":"user","content":"法国的首都是哪里？"}]},"output":{"answer":"巴黎"},"metadata":{"category":"地理"}}
```

每个非空行是一条样本。只接受 `input`、`output`、`metadata` 三个字段，值都必须是 JSON 对象；后两项可省略，默认 `{}`。不提交列选择。嵌套对象、数组、数字和布尔值保持原样。

两种格式的 `input` 都必须按目标 Agent 的请求体准备：Runner 会原样发送它。`output` 是评分器可用的参考输出。

## 响应

```json
{"dataset_id": 1, "dataset_version_id": 1, "example_count": 1}
```

`201` 表示已创建数据集、首个版本和全部样本，返回的 ID 可用于[创建实验](实验创建与查询.md)。本接口每次创建一个新数据集。

- `400`：上传表单格式错误；`401` / `403`：未登录或 CSRF 校验失败；`415`：请求不是文件表单。
- `409`：数据集重名；`413`：超过文件大小或样本数上限；`422`：字段、编码、列选择或数据内容无效。坏数据行会在错误信息中标出行号。
- 整份文件校验通过才开始写库；保存失败则整批回滚。
