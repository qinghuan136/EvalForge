# 数据集评分配置接口

接口使用浏览器登录 Cookie。新增配置还需提供 `X-CSRF-Token`，请求来源须通过现有校验。

| 方法 | 路径 | 成功响应 |
| --- | --- | --- |
| GET | `/api/v1/evaluators/builtin` | `200`，规则数组，每项有 `key`、`description`、`input_schema`、`output_configs` |
| GET | `/api/v1/datasets/{dataset_id}/evaluators` | `200`，按配置 ID 升序分页，返回 `items`、`page`、`pagesize`、`total` |
| POST | `/api/v1/datasets/{dataset_id}/evaluators` | `201`，返回已保存的配置，包括 `dataset_evaluator_id`、`dataset_id`、输入映射和默认输出定义 |

配置列表默认 `page=1`、`pagesize=20`，每页最多 100 条。数据集配置接口只接受当前用户拥有的数据集。

## 新增配置

```json
{
  "name": "category_match",
  "evaluator_key": "exact_match",
  "input_mapping": {
    "path_mapping": {
      "actual": "$.output.prediction.label",
      "expected": "$.reference.category"
    },
    "literal_mapping": {"case_sensitive": false}
  }
}
```

- `name` 去除首尾空白后须为 1–100 字符，且在同一数据集内唯一。`description` 可选，最多 2,000 字符。
- 参数名来自规则的 `input_schema`。必填参数须提供取值方式，每个参数只接受路径或固定值其中一种。省略可选参数时使用评分规则的默认值。
- 路径从 `$.input`、`$.reference`、`$.output` 或 `$.metadata` 开始，可选择整个值，也可通过 `.字段` 或 `[0]` 取子项。字段名以字母或下划线开头，后续可含字母、数字、下划线和连字符。路径最长 1,024 字符。
- 固定值使用规则声明的 JSON 类型，例如布尔值 `false`。保存时检查路径语法，具体样本中能否取到该值由评分时判定。
- 输出配置沿用平台默认分值、标签和优化方向，指标名使用这条数据集配置的 `name`。

| HTTP 状态 | `error.code` | 场景 |
| --- | --- | --- |
| 404 | `dataset_not_found` | 数据集不存在或不可访问 |
| 404 | `builtin_evaluator_not_found` | 规则键不存在 |
| 409 | `dataset_evaluator_name_conflict` | 同一数据集内配置重名 |
| 409 | `builtin_evaluator_name_conflict` | 数据库中的现有评分器占用了平台规则名 |
| 422 | `invalid_input_mapping` | 参数缺失、未知、重复配置，或路径与固定值不合法 |

创建实验时，用 `dataset_evaluator_ids` 选定本次配置。实验详情的 `evaluators` 字段返回创建时保存的快照。参见[实验接口](实验创建与查询.md)。
